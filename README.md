## Quick Sideload & Installation

1. Download **[AdSkipper-latest.apk](https://raw.githubusercontent.com/TusharTyagi-63/AdSkipper-App/main/AdSkipper-latest.apk)**.
2. Tap the downloaded APK and allow 'Install from Unknown Sources'.
3. Open **AdSkip Pro** and grant **Accessibility Permission** to start autonomous ad skipping.

Alternatively, install via ADB:
```bash
adb install -r -d -t AdSkipper-latest.apk
```
